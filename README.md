# Golnoush Haddadian - Personal Website

Academic portfolio of Golnoush (Lia) Haddadian, Ph.D. in Learning Sciences.

Live site: https://golnoushhaddadian.github.io

Built with Vite, React, TypeScript, Tailwind CSS, and shadcn/ui.

## Running locally

Install dependencies with npm install, then start the dev server with npm run dev. Build for production with npm run build.

## Deployment

The site deploys automatically to GitHub Pages via GitHub Actions on every push to the main branch.
